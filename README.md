# Zitel Communication Website

A responsive, beginner-friendly business website made with plain HTML, CSS, and JavaScript.

## Files included
- `index.html` — website content and page sections
- `style.css` — layout, colours, typography and responsive/mobile styling
- `script.js` — mobile navigation and current footer year

## Preview the website on your laptop
1. Download and extract `zitel-communication-website.zip`.
2. Open the extracted `zitel-communication` folder.
3. Double-click `index.html` to open it in your browser.
4. Keep your internet connection on for the Google Fonts. The main hero graphics are made with CSS, so no image downloads are required.

## Important details to update before publishing
- The phone/WhatsApp number is currently set to `+234 706 695 7990` based on details previously provided. Replace it if Zitel Communication uses a different number.
- The contact section currently says “Update with your business address” because a confirmed Zitel Communication address has not been supplied.
- Service descriptions are introductory examples. Edit them to match services you genuinely offer.
- The product cards are CSS illustrations, not listings of actual stock.
- This is a static website. It displays your services and links to WhatsApp; it does not take online payments, store customer details, or provide live stock/pricing.

## Publish for free with Netlify Drop
1. On your laptop, open `https://app.netlify.com/drop`.
2. Sign in or create an account if asked.
3. Extract the ZIP file first.
4. Drag the extracted `zitel-communication` folder (the folder containing `index.html`) into the upload area. If the page asks for a site folder, choose that folder rather than the ZIP file.
5. Wait for deployment to finish. Netlify will give you a public website address.
6. Open the address on your phone and check the menu, sections and WhatsApp link.

Netlify's interface may change over time. You can use a custom domain later if you buy one.

## Edit the website
- Open `index.html` in VS Code or another code editor to change text, contact details and services.
- Open `style.css` to adjust colours. The main colours are at the top inside `:root`.
- Open `script.js` if you want to change how the mobile menu works.
- To update the WhatsApp number, search in `index.html` for `2347066957990` and replace it with your country code and number without spaces, plus signs or dashes. Update both the WhatsApp link and visible phone number.
